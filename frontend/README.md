# 深研 · Research workspace

Vue 3 + TypeScript + Vite 前端。白色底面、蓝色强调色，面向研究任务、报告阅读和证据回查。直接使用现有 FastAPI API，不更改研究流程。

## 本地启动

要求 Node.js 22.12+（本次开发使用 24.12.0）。两个终端分别启动：

```powershell
# 终端 1：项目 backend 目录
uv run uvicorn deep_researcher.api.app:app --host 127.0.0.1 --port 8000 --workers 1
```

```powershell
# 终端 2：项目 frontend 目录
npm.cmd ci
npm.cmd run dev
```

打开 http://127.0.0.1:5173 。开发服务器将 `/api` 转发至 `http://127.0.0.1:8000`。可以在启动 Vite 前通过 `RESEARCH_API_URL` 环境变量覆盖目标地址。前端不需要、也不应保存模型密钥。

## 验证

```powershell
npm.cmd run build
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

浏览器测试使用拦截的 API 响应，不调用模型或搜索服务，不写入后端研究数据。覆盖创建、进度轮询、失败与中断恢复、网络错误、历史分页、删除与重试、侧栏折叠、报告目录、引用抽屉、Markdown 安全渲染、下载、刷新与移动布局。截图保存在忽略提交的 `test-results/` 中。

## 行为边界

- URL 使用 Hash 路由，详情页刷新后仍可根据完整 `run_id` 查询。
- 进度显示已提交的检查点，待执行节点不冒充精确实时执行信息。任务处理进度包含完成与跳过任务，不代表最终报告完成百分比。
- 查询可自动重试；创建和恢复不会自动重试。创建响应不确定时，必须先检查历史再手动提交。
- 页面隐藏时暂停轮询；切换研究取消旧请求。关闭网页不取消后台任务。
- 引用抽屉仅展示最终报告引用的证据，符合当前结果 API 的范围。
- 报告禁用原始 HTML，渲染后清理 HTML，再按已知证据编号生成引用按钮。代码片段中的编号不被替换。
- 选中侧栏记录后可删除；调用 `DELETE /api/research/{run_id}`，成功响应必须为 `204`。运行中或排队中的研究由后端返回 `409`。删除错误保留确认框及编号，允许手动重试；成功后返回新建页。需要使用已提供删除接口的后端版本。
- 桌面侧栏可完全折叠，偏好保存在浏览器；手机通过顶部菜单展开，不受桌面折叠偏好影响。
- 报告正文提供章节目录，目录定位不改变 Hash 路由。标题层级仅由前端排版增强，不修改生成的报告或下载内容。
- 暂不提供取消、文件上传和私有文档 RAG；网页研究已经接入后端 Web RAG。

## 动态进度的范围

沿用现有状态 API：执行期间每 2.5 秒查询；查询异常后按 5 秒重试；页面隐藏时暂停。前端展示阶段条、最近检查点待执行节点、任务高亮、已保存证据与摘要引用计数、上次同步时间，以及本页观察到的状态变化记录。

- `next_nodes` 表示检查点待执行的节点，不能作为服务端当前执行节点的精确证明。
- 进度条为已完成或已跳过任务数 / 本轮任务数。即使达到 100%，报告也可能还在汇总；只有 `report_ready` 才表示报告就绪。
- 执行动画只表示最近查询显示后台执行中，不是节点内部完成比例。连接异常、执行中断、页面隐藏、报告就绪时停止动画。
- 更新记录由两次查询结果的差异生成，最多保留 12 条，仅在当前详情页面内存中保存。刷新页面后从新快照开始，不重建虚构的历史事件，也不代表完整服务端日志。
## 流式报告

- 后端报告节点使用原生模型流式输出，通过 LangGraph custom 事件传出；规划、搜索、摘要仍按原流程执行。
- 事件保存在研究数据目录的 events.sqlite3，GET /api/research/{run_id}/events 提供 SSE。
- 浏览器断线或页面重新可见时，使用 after 游标补发；后端也支持标准 Last-Event-ID 请求头。刷新页面重新回放事件。事件编号去重，恢复执行/报告重新生成时清空上一轮草稿。
- 报告正文增量合并后发送，页面以纯文本展示草稿。最终引用校验和笔记保存完成后，由原有 /result 接口替换为正式 Markdown 报告。
- 阶段消息表示节点实际发出的开始/返回事件；检查点仍是恢复执行的依据。事件不写入 SummaryState，也不代替检查点。
- 流式连接失败不取消研究，进度轮询继续。研究删除同时清理事件；关闭页面不终止后台任务。
- 当前不提供工具参数流、模型推理过程、搜索逐条结果推送；恢复时会重新执行未完成的报告节点，不续写半份草稿。
- 前置代理应关闭 SSE 缓冲。没有增加前后端依赖。

## 生产构建

`npm.cmd run build` 生成 `dist/`。可以用 `npm.cmd run preview` 在本机预览。正式部署时需要静态托管 `dist/`，并由反向代理把 `/api` 转发给后端。Vite 开发服务不是生产服务器。当前后端按单用户、单进程运行，不应把无鉴权 API 直接公开到互联网。

## 目录

- `src/api.ts`：请求、取消、超时和统一错误。
- `src/composables/useResearch.ts`：详情轮询与生命周期。
- `src/App.vue`：布局、健康状态与历史分页。
- `src/views/`：创建与研究详情。
- `src/components/`：品牌图形、报告、证据抽屉。
- `src/components/ResearchProgress.vue`：快照阶段展示、计数和本页进度更新记录。
- `src/style.css`、`src/styles/report.css`：工作台与文档阅读样式。
- `tests/workspace.spec.ts`：浏览器交互验证。
